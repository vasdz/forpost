# Локальные данные

В репозиторий допускается только этот документ. Исходные и производные данные
хранятся исключительно локально в `data/raw` и `data/processed`, не добавляются
в Git и не передаются в CI или внешние сервисы.

Проверку периметра выполняют `.gitignore`, versioned Git hooks, CI и
server-side pre-receive guard. Не размещайте в этом каталоге и не переносите
в другие каталоги репозитория выгрузки, архивы, снимки или персональные данные.
