# Руководство пользователя локального стенда

## Перед началом

Откройте `http://127.0.0.1:3000` после запуска администратором. Стенд работает
только локально. Метки `observed`, `derived`, `proxy` и `simulated` важны:
simulated-черновик не означает отправку реальной заявки.

## Основные разделы

- «Обзор» — агрегаты текущего временного среза.
- «Схема объектов» — подтверждённая иерархия с условной, не географической схемой.
- «Журналы наблюдений» — observed-события, поиск, фильтры и решения по тревогам.
- «Отказы датчиков» — прогнозы и качество proxy-модели.
- «Уведомления» — полный путь от прогноза до решения и черновика.
- «Заявки» — локальные simulated-черновики без внешней отправки.

## Обработка прогнозного уведомления

1. Откройте «Уведомления». Если экспорт отсутствует или повреждён, интерфейс
   покажет «Уведомления недоступны»; это штатный fail-closed результат.
2. Выберите уведомление. Проверьте канал, вероятность, горизонт, версию модели,
   факторы и ограничения. Proxy-вероятность не равна диагнозу физического отказа.
3. Сопоставьте прогноз с блоком «Наблюдаемая телеметрия». Пустой блок означает,
   что в ограниченном снимке нет событий этого канала, а не отсутствие риска.
4. Оцените рекомендованное действие. Решение всегда принимает диспетчер.
5. Нажмите «Войти как диспетчер ОДС». Demo-сессия действует пять минут.
6. Выберите «Подтвердить риск», «Эскалировать» или «Отклонить прогноз», внесите
   содержательное обоснование и сохраните решение.
7. После подтверждения или эскалации нажмите «Создать черновик заявки». После
   отклонения кнопка недоступна. Backend проверяет последнее решение и срок,
   затем берёт объект, приоритет, действие и срок из текущего прогноза.
8. Перейдите по ссылке «Открыть заявки» и проверьте строку с `simulated`.

## Работа с временной шкалой и таблицами

Глобальная временная шкала влияет на связанные KPI, графики и журналы. Перед
экспортом CSV проверьте активные фильтры. CSV содержит только отображаемые
нормализованные поля; исходные файлы через интерфейс не выдаются.

## Сообщения об ошибках

| Сообщение/код | Что означает | Действие |
| --- | --- | --- |
| Уведомления недоступны / 503 | нет валидного ML-экспорта | не создавать искусственные данные; сообщить ML-инженеру |
| Требуется сессия / 401 | demo-сессия отсутствует или истекла | выполнить вход повторно |
| CSRF/Origin отклонён / 403 | запрос не принадлежит локальной сессии | обновить страницу; не отключать защиту |
| Некорректный ответ / 502 | нарушен контракт между слоями | передать администратору время и экран, без выгрузки данных |
| Черновик не создан | прогноз изменился, права/хранилище недоступны | повторно открыть уведомление и проверить состояние |

Не копируйте содержимое локального снимка или ML-артефактов во внешние сервисы.
