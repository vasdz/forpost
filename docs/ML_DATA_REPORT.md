# Локальный отчёт по данным и ML

Этот файл намеренно не содержит результатов анализа, характеристик конкретной
выгрузки, идентификаторов, временных границ, контрольных сумм или путей к
файлам. Такие сведения и все производные отчёты остаются только в
игнорируемом локальном контуре `data/`.

Перед обучением модели владелец данных должен локально подтвердить:

- допустимость каждого источника и поля для конкретной цели;
- отсутствие персональных и иных запрещённых к обработке значений;
- отсутствие утечки целевого события и временного смешения выборок;
- воспроизводимость подготовки данных в изолированной среде;
- разбиение по времени, метрики и независимую проверку качества;
- порядок хранения, доступа, удаления и резервного восстановления артефактов.

Результаты этих проверок не публикуются в Git, CI-артефактах, чатах или
внешних сервисах. До их утверждения интерфейс и API не должны показывать
модельные прогнозы, вероятности или рекомендации как фактические данные.
