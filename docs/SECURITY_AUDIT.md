## Граница данных

Исходные локальные данные не являются частью репозитория и не должны
передаваться в CI, внешние сканеры или иные внешние сервисы. Для этого
зафиксированы следующие технические меры:

- `.gitignore` исключает локальные данные в `data/`; единственное versioned
  исключение — безопасный `data/README.md`;
- `scripts/pre-commit-guard.mjs` блокирует любой путь `data/**`, кроме ровно
  `data/README.md`, и добавление чрезмерно большого blob;
- versioned hooks в `.githooks/` запускают эту проверку до коммита и перед
  отправкой ветки; на каждой рабочей копии их нужно включить командой
  `npm run hooks:install`;
- pre-push проверяет все отправляемые обновления веток, включая новую ветку и
  force-push, а непроверяемые теги и служебные refs отклоняет;
- стандартные `npm run dev` и `npm run start` привязаны к `127.0.0.1`.

Маршрут локального снимка не принимает `Host`, `Origin` или
`X-Forwarded-For` за подтверждение сетевого происхождения: это управляемые
клиентом заголовки. Единственная поддерживаемая граница для него — listener
launcher на `127.0.0.1`; reverse proxy, опубликованный Docker-порт и LAN
запрещены.

В репозитории добавлен шаблон `scripts/server-hooks/pre-receive` и исполняемый
`scripts/server-perimeter-guard.mjs` для bare-репозитория. Они используют ту
же проверку истории, включая исходный и конечный путь переименования, и
отклоняют типовые экспортные расширения вне корневого `data/`. Их фактическая
установка остаётся обязанностью администратора Git-хостинга.

Локальные hooks можно обойти флагами Git или изменением локальной
конфигурации. Поэтому абсолютной защитой остаётся server-side pre-receive/DLP
на Git-сервере. Reverse proxy и публикация локального снимка наружу не входят
в поддерживаемую конфигурацию.

Защищённый FastAPI-контур не принимает роли из `x-role`, `x-user-id` и других
клиентских заголовков. Отсутствующая или некорректная Bearer-схема получает
`401` и `WWW-Authenticate: Bearer`; формально корректный Bearer до подключения
доверенного LDAP/AD-провайдера получает `503`, а не временную роль. Модель RBAC
содержит dispatcher, analyst и admin, но не считается включённой до интеграции
провайдера идентичности.

## Зависимости и поверхность API

`apps/api/pyproject.toml` явно объявляет используемые runtime-зависимости,
включая `slowapi`, `forpost-platform` и совместимый
`typing-extensions>=4.16.0`. Чистая временная Python 3.12 среда была создана
без project-specific shim: установка editable-пакетов, `pip check` и импорт
FastAPI/SlowAPI/API прошли успешно.

Автоматические Swagger, ReDoc и OpenAPI endpoints FastAPI отключены, пока
доверенный поставщик идентификации отсутствует. Регрессионный тест требует
404 для этих путей.

Next.js сохранён в требуемой 15-й ветке. Проверенный узкий npm override не
может заменить точную вложенную версию PostCSS, заданную этим релизом Next:
после reify npm сохраняет старую вложенную версию и помечает дерево invalid.
`npm audit --omit=dev --audit-level=high` поэтому сохраняет один high и один
moderate advisory, исправление которых предлагает смену Next на следующий
major. Такой major-апгрейд не выполнен, поскольку он противоречит текущему
требованию стека; риск нужно пересмотреть при разрешённом обновлении Next.

## CI

GitHub Actions закреплены полными commit SHA, а не mutable tags. Semgrep job
отключает отправку метрик и проверку версии, запускает локальную валидацию
конфигурации и исключает `data`, `node_modules`, `.next` и `references`.
Каждый job, кроме `perimeter-guard`, зависит от успешного `perimeter-guard`,
поэтому установка зависимостей и сканеры не запускаются параллельно с проверкой
изменений.

Registry-профили Semgrep загружаются извне. Их разрешено использовать только
в CI checkout, в который исходные данные не попадают; это обеспечивается
игнорированием, локальным guard и обязательным server-side pre-receive/DLP.

Локальный TruffleHog запускается только с явным списком исходного кода и
конфигурации, без корня рабочей копии. Его исключение использует кроссплатформенный
разделитель путей для дополнительной защиты корневого `data/`. Legacy-
`apps/web` исключён из локального target из-за зависимостей с опубликованными
документационными URI; его отслеживаемая история остаётся в TruffleHog CI.
