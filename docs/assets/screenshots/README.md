# Реальные скриншоты для экспертизы

Добавляйте только скриншоты работающего локального интерфейса без raw data,
реальных ID, персональных данных или секретов. Не заменяйте их макетами.

Снимите после `npm run dev:stack`:

1. `01-overview.png` — `/`, источник и observed-данные.
2. `02-ml-quality.png` — `/sensor-failure`, proxy/evidence tier и quality panel.
3. `03-notifications.png` — `/notifications`, прогноз, факторы и telemetry.
4. `04-decision-applications.png` — решение и `/applications`, только simulated draft.

Перед добавлением удалите или замаскируйте любые значения, которые политика
проекта не разрешает публиковать. Если безопасно подготовить скриншот нельзя,
оставьте каталог без изображений.
