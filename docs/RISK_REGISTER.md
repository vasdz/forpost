# Реестр известных рисков

## R-001 — транзитивные уязвимости PostCSS в Next.js 15.5.25

**Статус:** принят до окончания хакатона.
**Источник:** `npm audit --omit=dev --json`, 15 сентября 2026 года.
**Затронутый путь:** `next@15.5.25` → `postcss@8.4.31`.

`npm audit` сообщает **1 high** и **1 moderate** агрегированных уязвимости.
В отчёте отсутствуют CVE-идентификаторы; указаны следующие GitHub Security
Advisory:

- GHSA-qx2v-qp2m-jg93 — XSS при неэкранированном `</style>` в CSS stringify
  (moderate, CWE-79);
- GHSA-6g55-p6wh-862q — чтение произвольного файла через
  контролируемый `sourceMappingURL` (high, CWE-22/CWE-200);
- GHSA-fxqj-rqcc-2cmp — неполное исправление чтения `.map`-файлов
  (moderate, CWE-22/CWE-200);
- GHSA-r28c-9q8g-f849 — path traversal при автозагрузке source map
  (high, CWE-22).

В отчёте нет RCE или prototype-pollution. Исправление, предлагаемое npm,
требует мажорного обновления до `next@16.3.5`; оно отложено, чтобы не вносить
breaking changes в период хакатона.

**Компенсирующие меры:** локальные команды `npm run dev` и `npm run start`
жёстко привязывают Next.js к `127.0.0.1`; приложение не публикует порт и не
обрабатывает загружаемый пользователем CSS. Это уменьшает практический риск,
но не отменяет необходимость обновления.

**План:** после хакатона обновить Next.js и `eslint-config-next` до 16.3.5,
запустить рекомендованный codemod, затем повторить `npm audit`, unit/E2E
тесты и production build до закрытия риска.
