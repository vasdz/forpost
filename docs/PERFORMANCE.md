# Производительность inference

В репозитории нет опубликованного измерения inference: политика локального
периметра не разрешает включать свойства конкретных данных, model artefacts
или результаты их обработки в Git. Поэтому SLA не заявляется.

## Воспроизводимое локальное измерение

На машине владельца данных после подготовки snapshot и валидного `v10` release
замерьте отдельно feature construction, scoring, export и total time в
изолированном локальном журнале. Для каждого запуска сохраните только локально:

- ОС, Python, CPU и версию model release;
- число объектов/каналов и размер входа;
- времена этапов и total; p50/p95 для повторных запусков;
- scope и ограничения измерения.

Сравнивайте total batch inference с требованием ТЗ о времени прогноза, но не
выводите SLA из одного локального запуска. Нельзя направлять snapshot, model
bundle или benchmark output во внешние сервисы. Методика модели — в
[ML_METHODS.md](ML_METHODS.md), локальный периметр — в
[LOCAL_VERIFY.md](LOCAL_VERIFY.md).
