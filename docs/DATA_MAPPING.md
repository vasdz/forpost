# Контракт локального снимка

## Назначение

Документ фиксирует публичный минимальный контракт между локальным адаптером и
интерфейсом. Он не содержит названий исходных файлов, записей, идентификаторов,
размеров, контрольных сумм или иных фактов о конкретной полученной выгрузке.

Первичные локальные CSV не являются API-контрактом. Адаптер допускает только
согласованные схемы, нормализует их в ограниченный JSON-снимок и отклоняет
неизвестные, неполные или дублирующие роли. Исходные поля и внутренние пути не
передаются браузеру.

## Целевая схема Приложения 1

Ниже приведён контракт из ТЗ, а не инвентаризация конкретной выгрузки. Его
строго проверяет `AppendixOneExcelLoader`; успешная проверка должна выполняться
только локально и не публикует результат в Git.

| Поле контракта ТЗ | Сущность домена | Поле будущего API/БД |
| --- | --- | --- |
| ИД записи журнала | Наблюдение журнала | `event_id` |
| ИД канала данных | Наблюдение / канал | `channel_id` |
| ИД типа канала данных | Тип канала | `channel_type_id` |
| Текущее значение | Наблюдение журнала | `current_value` |
| Дата записи | Наблюдение журнала | `recorded_at` |
| Тег в дереве объектов | Канал / объектная связь | `object_tag` |
| Название типа канала | Тип канала | `name` |
| Диспетчерское название типа | Тип канала | `dispatch_name` |
| ИД записи дерева | Узел дерева | `record_id` |
| ИД системы | Узел дерева | `system_id` |
| Диспетчерское название узла | Узел дерева | `dispatch_name` |
| Название узла | Узел дерева | `name` |

Контрактные XLSX-файлы допускаются только из разрешённого локального корня,
проходят проверку формата, архива, размера, числа строк, полного набора колонок
и ссылочной целостности. Имена реальных файлов, результат проверки и факты о
конкретной выгрузке в этом документе намеренно отсутствуют.

## Публичная структура

| Раздел снимка | Смысл | Ограничение |
| --- | --- | --- |
| `sourceAvailability` | Явная доступность классов источников | `false` не заменяется вычисленным значением |
| `channels` | Описания наблюдаемых каналов | Только атрибуты, разрешённые контрактом |
| `objects` | Негеографическая иерархия объектов | Без координат и картографического вывода |
| `events` | Ограниченная выборка наблюдаемых событий | Факт наблюдения, не прогноз и не диагноз |

`isAlarm` — только переданный признак источника. Он не является оценкой
критичности, вероятностью инцидента, классификацией ложного срабатывания или
рекомендацией. Если значение не подтверждено схемой, в контракт передаётся
`null`.

## Границы преобразования

Контракт не создаёт вероятности, горизонты, версию модели, диагнозы,
историю ремонтов, допуски, события доступа, заявки, погоду или геоданные.
Наличие таких значений требует отдельного подтверждённого источника, схемы и
контролируемой интеграции. До этого соответствующие маршруты UI и API
возвращают явную недоступность.

## Защита пути и объёма

Скрипт подготовки разрешает чтение только в локальном корне источника и запись
только в локальном корне производных данных. Путь не приходит из HTTP-запроса.
Внутренние служебные метаданные не сериализуются в JSON-снимок и не доступны
серверному маршруту или браузеру.
Серверный маршрут читает единственный фиксированный файл через проверенный
канонический путь, проверяет размер и строгую JSON-схему до выдачи ответа.
Производный файл остаётся игнорируемым Git.
