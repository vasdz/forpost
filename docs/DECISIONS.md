# Зафиксированные решения по объёму

## ADR-001: картографическое представление

**Статус:** принято для текущей фазы данных.

ТЗ предусматривает интерактивную карту объектов. Действующая дизайн-спецификация
запрещает географические карты, а в текущем локальном контракте нет
подтверждённых координат. По прямому требованию пользователя геокарта заменена
на timeline-playback и негеографическую схемную топологию/рейтинг участков.
Такая замена не создаёт координаты, потоковую геопередачу или показатели риска.

Для реализации решения допустимы только следующие реальные входы:

1. подтверждённая негеографическая иерархия объектов для схемной топологии;
2. подтверждённые факты наблюдений для временной шкалы;
3. отдельный утверждённый источник, если понадобится рейтинг участков.

Timeline-playback реальных наблюдений уже реализован. Схемная топология и
рейтинг намеренно не подменяются демонстрационными узлами: они остаются
частично реализованными, пока в интерфейсе не появится представление разрешённой
реальной иерархии без геоданных.
