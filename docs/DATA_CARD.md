# Data Card локального ML-контура

## Назначение

Этот файл задаёт безопасный формат локальной Data Card. Он намеренно не
содержит строки, идентификаторы, временные границы, размеры, хэши или даже
агрегаты конкретной выгрузки: политика [DATA_INVENTORY.md](DATA_INVENTORY.md)
не допускает такие производные сведения в Git, CI-артефакты или документацию.

## Локальное заполнение владельцем данных

Сгенерируйте Data Card только в игнорируемом локальном каталоге после проверки
прав доступа и обезличивания. Не копируйте результат обратно в этот файл.

| Поле | Локальное значение |
| --- | --- |
| Период данных | Не публикуется в Git; заполнить локально. |
| Количество записей/каналов/событий | Не публикуется в Git; заполнить локально. |
| Распределение типов | Не публикуется в Git; заполнить локально. |
| Доля proxy outcomes | Не публикуется в Git; заполнить локально. |
| Цензурирование и пропуски | Описать локально без идентификаторов. |
| Источник snapshot | `scripts/build_local_snapshot.py`, локально. |
| Обезличивание | Подтверждается владельцем источника до локальной обработки. |

## Семантика набора

Локальный dataset состоит из обезличенных журналов наблюдений и справочника
каналов, минимизированных в local snapshot. Точная глубина, состав и агрегаты
конкретной выгрузки не публикуются. Для `sensor_failure` target —
`cadence_adjusted_silence_horizon_proxy_v2`: proxy неожиданного прекращения
ожидаемой телеметрии на горизонте 24 часа. Он не доказывает физическую
неисправность датчика. Источники для пожара, доступа и износа не включены в
текущий modelled dataset; их отсутствие не заменяется synthetic prediction.

## Ограничения

Snapshot не доказывает качество трёх отсутствующих направлений. Для
`sensor_failure` outcome — `cadence_adjusted_silence_horizon_proxy_v2`, а не
физический отказ. См. [ML_METHODS.md](ML_METHODS.md) и
[ML_CAPABILITIES.md](ML_CAPABILITIES.md).
