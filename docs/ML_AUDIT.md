# Аудит ML-части

Аудит проведён до запуска обучения. Он описывает только исходный код и контракты
репозитория: сведения о локальной выгрузке и вычисленные факты намеренно не
публикуются.

| Артефакт | Путь | Состояние | Решение | Обоснование |
| --- | --- | --- | --- | --- |
| Абстрактный предиктор | `packages/prediction/src/forpost_prediction_core/base.py` | частично | ДОРАБОТАТЬ | Есть общий интерфейс, но нет реализации модели, feature store, обучения, калибровки или реестра. |
| Валидация телеметрии | `packages/prediction/src/forpost_prediction_core/telemetry_guard.py` | частично | ДОРАБОТАТЬ | Правила диапазонов не являются обученной моделью и требуют подтверждения единиц измерения перед использованием как признаки. |
| Доменные сущности риска | `packages/domain/src/forpost_domain/risks/entities.py` | рабочее | ПЕРЕИСПОЛЬЗОВАТЬ | Контракт вероятности, категории, горизонта и версии пригоден как внутренний адаптер. |
| API рисков | `apps/api/src/forpost_api/routes/v1/risks.py` | рабочее защитное ограничение | ДОРАБОТАТЬ | Маршрут корректно сообщает недоступность, пока нет проверенной модели и источника; он не генерирует синтетические прогнозы. |
| Аналитика и заявки | `packages/platform/src/forpost_platform/analytics/`, `packages/platform/src/forpost_platform/maintenance/` | частично | ДОРАБОТАТЬ | Код обрабатывает уже полученный доменный объект, но не формирует и не валидирует ML-прогноз. |
| Обучающие скрипты и notebooks | отсутствуют | отсутствует | С НУЛЯ | В репозитории нет train/predict/evaluate/retrain-контура. |
| ML-библиотеки и модельные артефакты | файлы зависимостей и репозиторий | отсутствует | С НУЛЯ | Нет закреплённого ML-стека и нет версионированных локальных артефактов модели. |
| UI-контракт будущего прогноза | `docs/SPEC.md` | рабочее | ПЕРЕИСПОЛЬЗОВАТЬ | Контракт остаётся замороженным; UI не должен вычислять или получать невалидированные прогнозы. |

## Вывод

Рабочей ML-реализации в проекте нет. Переиспользуются только безопасный контракт
риска, доменные категории и явный ответ о недоступности. Обучение допускается
только после локальной проверки схемы, временной разметки, достаточного числа
подтверждённых позитивных событий и отсутствия утечки будущего.

До этого момента API продолжает возвращать явную недоступность. Это намеренно:
правдоподобная вероятность без верифицированных лейблов, калибровки и holdout
проверки была бы ложным утверждением о состоянии инфраструктуры.
